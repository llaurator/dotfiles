# Security Policy

## Private data

Do not commit or publicly report secrets. Private keys, access tokens, passwords, and private user configuration do not belong in this repository.

If you discover a secret already exposed, do not copy it into an issue, pull request, discussion, or other public channel.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting mechanisms when they are available for this repository. Do not include sensitive details in a public report.

If no private reporting channel is available, ask for one without publishing the vulnerability details. Wait for a private channel before sharing reproduction steps, affected data, or any secret material.
